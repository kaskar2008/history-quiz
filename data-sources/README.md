# Внешние источники вопросов

Эта папка хранит сырые данные, собранные из открытых баз вопросов по истории
и использованные как фактологическая опора и источник тем при расширении
базы вопросов приложения (см. `src/data/questions/`).

## Источники

1. **Open Trivia Database (OpenTDB)**, категория History (id 23).
   `external/opentdb_history.json` — 399 вопросов с вариантами ответов,
   уровнем сложности (easy/medium/hard) и языком английский. Публичный
   бесплатный API (`opentdb.com`), созданный специально для использования
   в сторонних тривиа-приложениях.
2. **The Trivia API** (`the-trivia-api.com`), категория history.
   `external/the-trivia-api_history.json` — 796 вопросов, также в формате
   вопрос/правильный ответ/неверные ответы, с тегами по темам. Публичный
   бесплатный API, ориентированный на разработчиков квиз-приложений.
3. **OpenTriviaQA** (github.com/uberspot/OpenTriviaQA), категория history.
   `external/opentriviaqa_history.json` — 1645 вопросов, разобранных из
   исходного текстового формата репозитория. Датасет распространяется по
   лицензии Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0).
   Это открытый краудсорсинговый набор, качество и достоверность отдельных
   вопросов не гарантированы издателем.

Итого собрано **2840** сырых вопросов на английском языке (после очистки
HTML-сущностей и разбора текстового формата).

## Как источники использовались

Прямой машинный перевод исходных вопросов не производился: формулировки на
английском часто не соответствуют разговорному стилю русского квиза, часть
вопросов OpenTriviaQA не относится к истории строго (поп-культура, обиходные
факты) или требует проверки достоверности. Вместо этого источники служили
источником тем, дат и персоналий, охватывающих периоды и регионы, которые
недостаточно раскрыты в исходной базе (особенно неевропейские регионы:
Африка, Юго-Восточная Азия, Океания, Латинская Америка). На их основе и с
опорой на общие исторические знания были написаны новые вопросы на русском
языке в формате приложения (см. `src/data/types.ts` и раздел 6 `README.md`
в корне репозитория), с собственными вариантами ответов, пояснениями и
метаданными (регион/период/темы/страны/годы), прошедшие валидацию
`npm run validate:questions`.

## Лицензии и использование

- OpenTDB и The Trivia API — публичные API, явно предназначенные для
  использования в некоммерческих и коммерческих тривиа-приложениях.
- OpenTriviaQA — CC BY-SA 4.0, требует указания источника при дальнейшем
  распространении. Ссылка на источник: https://github.com/uberspot/OpenTriviaQA

Сырые файлы хранятся здесь как справочный материал и для прозрачности
происхождения контента; они не используются приложением напрямую (не
импортируются в `src/`).
